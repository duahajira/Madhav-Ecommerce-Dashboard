# Madhav Ecommerce Sales Dashboard (Power BI)

## Project Overview
This project is an interactive E-commerce Sales Dashboard created using Microsoft Power BI. It provides deep insights into sales performance, profit trends, and customer behavior.

## Key Features
- KPI Cards: Total Amount, Total Profit, Total Quantity, and Average Order Value (AOV).
- Visualizations:
  - Monthly Profit Trends (Bar Chart)
  - Sales by State (Horizontal Bar Chart)
  - Quantity by Category (Donut Chart)
  - Quantity by Payment Mode (Donut Chart)
  - Top Customers by Amount (Bar Chart)
  - Profit by Sub-Category (Bar Chart)
- Slicers: Dynamic filtering by Quarter (Qtr 1 to Qtr 4).
- UI Design: Custom dark theme background with white typography for a modern look.

## Tools & Technologies Used
- Power BI Desktop
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions for Measures)
